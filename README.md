# 🎮 My Browser Games

Small games I built with HTML, CSS and JavaScript. Play them right in your browser.

## ⚔️ Mini Swordigo
A 2D side-scrolling action platformer inspired by the mobile game Swordigo.

▶️ **Play:**https://neekhilnavik2-art.github.io/my-web-projects/swordigo.html 

**Features**
- Run, jump and fight enemies with a sword
- Collect coins, parallax background, hit effects
- Sound effects (made with Web Audio API)
- Mobile touch controls

**Controls**
- Move: `←` `→` (or `A` `D`)
- Jump: `↑` (or `W`)
- Attack: `Space`
- Mute: `M`
- On phone: use the on-screen buttons
